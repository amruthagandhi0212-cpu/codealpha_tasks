# CodeAlpha Data Analytics Internship

## Overview

This repository contains the projects I completed during my Data Analytics Internship at CodeAlpha. The internship provided me with an opportunity to gain practical experience in data collection, analysis, visualization, and text analytics using Python.

Through these projects, I explored different stages of the data analytics workflow, from gathering data to extracting insights and presenting results effectively.

## Projects Included

### Task 1: Web Scraping

* Collected data from web pages using Python.
* Extracted and stored relevant information in a structured format.
* Learned the basics of HTML parsing and data extraction.

### Task 2: Exploratory Data Analysis (EDA)

* Explored and analyzed datasets using Pandas.
* Identified data patterns, missing values, and summary statistics.
* Generated insights to better understand the dataset.

### Task 3: Data Visualization

* Created visual representations of data using Matplotlib.
* Developed bar charts and pie charts to present insights clearly.
* Improved understanding of data storytelling through visualization.

### Task 4: Sentiment Analysis

* Built a sentiment analysis tool using Python and TextBlob.
* Classified user-provided text as Positive, Negative, or Neutral.
* Gained practical exposure to basic Natural Language Processing (NLP) concepts.
