# Task 1 - Web Scraping

## Introduction

As part of my CodeAlpha Data Analytics Internship, I completed a web scraping project to gain practical experience in collecting data from websites using Python.

The objective of this task was to extract book information from a website and store the collected data in a structured format for further analysis.

## Project Description

In this project, I used Python along with the Requests and BeautifulSoup libraries to access a website, retrieve its HTML content, and extract book titles and prices. The extracted data was then organized using Pandas and saved into a CSV file.

This project helped me understand how websites are structured and how useful information can be collected programmatically.

## Tools and Technologies Used

* Python
* Requests
* BeautifulSoup
* Pandas
* VS Code
* GitHub

## Website Used

Books to Scrape

https://books.toscrape.com

## Implementation Process

1. Connected to the website using the Requests library.
2. Retrieved the HTML source code of the webpage.
3. Parsed the HTML content using BeautifulSoup.
4. Identified the required elements containing book titles and prices.
5. Extracted the data and stored it in Python lists.
6. Created a Pandas DataFrame from the extracted data.
7. Exported the final dataset into a CSV file.

## Project Output

The project successfully generated a CSV file containing book titles and their corresponding prices.

Output File:

* books.csv
